VASU DRIVING SCHOOL - START HERE

1. Extract this ZIP.
2. Open the MAIN folder in VS Code.
3. Open Terminal in the main folder.
4. Run:

   npm run install:all

5. Start backend in Terminal 1:

   cd backend
   npm run dev

6. Start frontend in Terminal 2:

   cd frontend
   npm run dev

7. Open:

   http://localhost:5173

8. Test backend:

   http://localhost:5000/api/health

IMPORTANT:
- 5000 = backend/API
- 5173 = React website
- MongoDB is NOT required for the first local test.
- Local testing uses backend/data/db.json.

For code customization, read CODE-GUIDE.md.
